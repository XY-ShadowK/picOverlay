# Option Details:

## `-i, --input`

`-i [FILENAME]` or `--input [FILENAME]`
`[FILENAME]` is action process file's name.

## `--source`

`--source [DIRECTORY]`
`[DIRECTORY]` is origin directory for read pictures.

## `--destination`

`--destination [DIRECTORY]`
`[DIRECTORY]` is output directory for generated pictures.

## `--buffer-x`

`--buffer-x [NUM]`
`[NUM]` is buffer width.

## `--buffer-y`

`--buffer-y [NUM]`
`[NUM]` is buffer height.

## `--custom-name`

When this option is enabled, you must use `generate filename` to explictly specify generated filename.

## `-h, --help`

Printf help information.
